Privacy, in plain language.

PixelMint Tools processes supported images directly in your browser. This page explains what that means.

Your image files

When you select images, your browser reads them locally and creates a processed copy on your device. PixelMint does not upload those files to a PixelMint server. The original file is not changed. Image processing happens in your browser using its image and canvas features.

Temporary browser data

The tool may create temporary in-memory copies and preview URLs so you can see and download your result. These are used while the tool is open. If you use “Continue in…” to move an output between tools, a temporary copy is placed in this browser’s IndexedDB and removed when the destination tool reads it. If you leave before continuing, you can remove the pending copy by clearing site data for PixelMint in your browser settings.

Accounts and tracking

This first version does not require an account. We have not added advertising or analytics tracking to the tool.
