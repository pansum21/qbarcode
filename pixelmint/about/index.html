About PixelMint Tools.

A small, practical toolkit for everyday image tasks: make files lighter, change formats, resize to exact pixels, and prepare a portrait crop.

Image tools that stay simple

PixelMint Tools is built around a common problem: an image is almost ready, but it is too large to upload, in the wrong format, or the wrong dimensions. The tools help make that one change quickly in your browser. No account or software installation is needed.

Compress an image

The image compressor creates a smaller copy in WebP, JPG, PNG, or the original supported format. Choose an output quality and, for JPG or WebP, an optional maximum size in KB. The tool reports the original and output file sizes so you can see what changed before downloading.

Convert image formats

The image converter can create JPG, PNG, or WebP copies. JPG is broadly compatible and does not preserve transparency; transparent pixels are filled with white. PNG supports transparency but can be larger. WebP is a modern web format and can often produce smaller files for photos. The best choice depends on where the image will be used.

Resize to exact dimensions

Set a width, height, or both in pixels. Lock the aspect ratio to keep the image proportional, or unlock it when you intentionally need exact independent dimensions. Resizing changes pixel dimensions; it does not add detail that was not present in the original.

Passport and ID photo maker

Choose a portrait crop ratio, position the image, adjust zoom, and export a cropped image. The presets are convenient starting points for common print proportions. Requirements differ by country and application, so check the receiving authority’s current photo rules before submitting. PixelMint does not certify that a photo meets a government’s biometric, background, face-size, or print requirements.

One workflow across tools

After processing, use “Continue in…” to pass the output to another PixelMint tool without downloading and selecting it again. This handoff is stored temporarily in this browser’s local IndexedDB and is read by the destination page. For example, crop a portrait, resize it, convert the format, or compress the final copy. Your original file remains unchanged.

Private by design

Image decoding, cropping, resizing, format conversion, and compression run in your browser using browser image and canvas capabilities. PixelMint does not need to upload the image to process it. Browser support and available memory can affect very large files. A temporary local handoff may remain in browser storage until the next tool consumes it; clear site data in your browser to remove any pending handoff.

Free to use

PixelMint Tools is free to use and does not require registration. There are no paid tiers or export limits in the current tool experience. We aim to keep the controls clear: select an image, choose the output settings, process, inspect the result details, and download the copy you need.

Independent project
